ТЕРМІНАЛ (PowerShell) у d:\HikingApp\hiking_app:

  npx supabase@latest login
  npx supabase@latest link --project-ref ВАШ_REFERENCE_ID
  npx supabase@latest secrets set OPENAI_API_KEY=sk-...
  (перевірка: npx supabase@latest secrets list — має бути OPENAI_API_KEY)

  npx supabase@latest functions deploy ai-chat
  npx supabase@latest functions deploy recommend-routes
  npx supabase@latest functions deploy trip-actions
