ТЕРМІНАЛ (PowerShell) — ОБОВʼЯЗКОВО спочатку перейдіть у папку проєкту:

  cd d:\HikingApp\hiking_app

  (Якщо запускати з C:\Users\Марта — буде помилка
   «cannot find path supabase\functions\...»)

  Вхід у CLI (якщо «could not create sign-in session» — див. нижче):
  npx supabase@latest login --token sbp_ВАШ_ТОКЕН
  (токен: https://supabase.com/dashboard/account/tokens → Generate new token)

  npx supabase@latest link --project-ref ВАШ_REFERENCE_ID

  npx supabase@latest secrets set OPENAI_API_KEY=sk-...
  npx supabase@latest secrets set OPENWEATHER_API_KEY=...
  npx supabase@latest secrets set GRAPHOPPER_API_KEY=...

  npx supabase@latest functions deploy ai-chat
  npx supabase@latest functions deploy recommend-routes
  npx supabase@latest functions deploy trip-actions
  npx supabase@latest functions deploy route-hike
  npx supabase@latest functions deploy weather
  npx supabase@latest functions deploy geosearch
  npx supabase@latest functions deploy poi-nearby
  npx supabase@latest functions deploy save-route
  npx supabase@latest functions deploy prepare-offline-route
  npx supabase@latest functions deploy trip-chat

───────────────────────────────────────────────────────────────
Edge Functions
───────────────────────────────────────────────────────────────

  ai-chat                 — ШІ-чат
  recommend-routes        — рекомендації маршрутів
  trip-actions            — походи: apply, decide, cancel, create, update, close, complete, leave
  route-hike              — GraphHopper/OSRM маршрутизація
  weather                 — OpenWeather (current, forecast, route, city)
  geosearch               — Nominatim/Photon/Overpass пошук місць
  poi-nearby              — POI на карті (Overpass)
  save-route              — створення/редагування маршруту + geojson
  prepare-offline-route   — полілінія для офлайн-пакета
  trip-chat               — чат: list / send + сповіщення new_message

Клієнт має локальний fallback (якщо Edge ще не задеплоєно).

Realtime (обовʼязково для чату в реальному часі):
  supabase/realtime_publication.sql — messages, notifications, trip_participants, trips

Reference ID: Dashboard → Project Settings → General

───────────────────────────────────────────────────────────────
Якщо login не відкриває браузер / Unknown error
───────────────────────────────────────────────────────────────

1) Токен вручну (найнадійніше на Windows):
   https://supabase.com/dashboard/account/tokens
   → Generate new token → скопіювати (sbp_...)

   cd d:\HikingApp\hiking_app
   npx supabase@latest login --token sbp_xxxxxxxx

2) У PowerShell при вводі токена символи НЕ видно — це нормально.
   Вставте Ctrl+V і натисніть Enter.

3) Секрети можна додати без CLI:
   Dashboard → Project Settings → Edge Functions → Secrets

4) Якщо deploy уже працював — login може не знадобитись;
   спробуйте одразу: npx supabase@latest functions deploy weather
