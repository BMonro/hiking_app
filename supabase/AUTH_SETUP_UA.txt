================================================================================
Hikora — налаштування автентифікації (Supabase Dashboard)
================================================================================
Якщо не працює Google OAuth або підтвердження email — виконайте кроки нижче.

Проєкт: https://supabase.com/dashboard → ваш проєкт → Authentication

--------------------------------------------------------------------------------
1. URL Configuration (обовʼязково)
--------------------------------------------------------------------------------
Authentication → URL Configuration

Redirect URLs (додати ВСІ рядки):
  io.supabase.flutter://login-callback/
  io.supabase.flutter://login-callback

Site URL (можна залишити URL проєкту):
  https://ВАШ_PROJECT_REF.supabase.co

--------------------------------------------------------------------------------
2. Google OAuth
--------------------------------------------------------------------------------
Authentication → Providers → Google → Enable

У Google Cloud Console (https://console.cloud.google.com):
  APIs & Services → Credentials → OAuth 2.0 Client ID (Web application)

Authorized redirect URIs (додати):
  https://ВАШ_PROJECT_REF.supabase.co/auth/v1/callback

Скопіювати Client ID і Client Secret у Supabase → Google provider.

На телефоні: після входу браузер має повернути в застосунок (deep link).
У застосунку вже налаштовано: io.supabase.flutter://login-callback/

У застосунку для Google передається prompt=select_account — екран вибору
акаунта (не автоматичний вхід останнім). Якщо все одно входить «само» —
вийдіть з Google у браузері на пристрої або очистіть дані Chrome.

--------------------------------------------------------------------------------
3. Підтвердження email (реєстрація за поштою)
--------------------------------------------------------------------------------
Authentication → Providers → Email

У застосунку використовується PKCE (не implicit) — це потрібно для Google OAuth на Android.

Варіант А (для розробки / диплома — найпростіше):
  Вимкніть "Confirm email" → зберегти.
  Після signUp користувач одразу отримує сесію, без листа.

Варіант Б (з підтвердженням на телефоні):
  Увімкніть "Confirm email".
  У Redirect URLs мають бути io.supabase.flutter://login-callback/ (див. п.1).
  Лист відкривайте НА ТОМУ Ж ТЕЛЕФОНІ, де реєструвались (інакше otp_expired).
  Після кліку застосунок має відкритися автоматично.

Якщо лист відкривається в Chrome і «нічого не відбувається»:
  — перевірте Redirect URLs;
  — відкрийте лист на телефоні з встановленим Hikora, не на ПК.

--------------------------------------------------------------------------------
4. Після змін у Dashboard
--------------------------------------------------------------------------------
Перезапустіть застосунок (flutter run).
Edge Functions передеплоювати НЕ потрібно.

--------------------------------------------------------------------------------
5. Перевірка
--------------------------------------------------------------------------------
[ ] Email: реєстрація → або одразу крок 2 профілю, або лист → відкриває застосунок
[ ] Google: кнопка → браузер Google → повернення в застосунок → /home або /register?oauth=1
[ ] Вхід email/пароль після підтвердження
